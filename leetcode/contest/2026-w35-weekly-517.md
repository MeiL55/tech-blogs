## Q1. Count Integers Appearing in a Single Block

**链接**: https://leetcode.com/contest/weekly-contest-517/problems/count-integers-appearing-in-a-single-block/description/

### 思路
其实主要看的是contiguous block两个number是不是一样，所以可以用i和i+1判断，但是有很多边界条件需要考虑：不可以重复算一个number，最后一个number要考虑。想到不可以重复，可以用set。但是在如果看到同一个number在不同block怎么改变count卡住了，gemini给的方法是用另一个set，如果这个number已经出现过第二次了，count要-1，从而抵消。

总感觉会有更简单的方法：用hashmap，map[x]=1 代表数字x有1个block，return count of map[x]=1

### 代码
```python
class Solution(object):

    def countSpecialIntegers(self, nums):
        """
        :type nums: List[int]

        :rtype: int
        """
        seen_before = set()
        invalid = set()
        count = 0

        for i in range(len(nums)):
            # If we see an element from a past block, it's not special
            if nums[i] in seen_before:
                if nums[i] not in invalid:
                    invalid.add(nums[i])
                    count -= 1  # Revoke previous valid count
                continue

            # Check if current block ends at index i
            is_end_of_block = (i == len(nums) - 1) or (nums[i] != nums[i + 1])

            if is_end_of_block:
                seen_before.add(nums[i])
                count += 1

        return count
```

### 复杂度
- 时间: O(n)
- 空间: O(n)

## Q2. Sum of Decoded Numbers

**链接**: https://leetcode.com/problems/sum-of-decoded-numbers/description/

### 思路
思路很简单，用helper function就能解决。x和y需要用下substring和int转换，为了避免overflow，所有result都要mod。

### 代码
```python
class Solution(object):
    MOD = 10**9+7
    def sumDecoded(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        sum = 0
        for num in nums:
            sum = (sum + self.helper(num)) % self.MOD
        return sum
    def helper(self, num):
        width = num % 10
        d = num // 10
        d_str = str(d)
        x = int(d_str[:width])
        y = int(d_str[width:])
        # binary exponentiation
        res = pow(x, y, self.MOD)
        return res
```

### 复杂度
- 时间: O(n log y), y is length of longest number
- 空间: O(1)

### 分析
 - ood基本concept：constant要有self，helper function要有self
 - floor divide: //, divide: / 和java不一样
 - cast：str(), int()
 - substring: str[:i]
 - **为什么要 mod `10^9+7`：** 算出来的大数可能会有几万位，不 mod 会暴内存（MLE）或算得极慢（TLE）
 - **为什么要用 binary（快速幂）：** 如果用普通乘法连乘 $y$ 次太慢了。快速幂折半计算，把次数从 $y$ 降到 $\log y$。Python 的 `pow(x, y, self.MOD)` 底层就是偶数次幂divide&conquer, 是binary

## Q3. Minimum Operations to Form Subset Sum I

**链接**: https://leetcode.com/problems/minimum-operations-to-form-subset-sum-i/

### 思路
这是一道0/1 knapsack，因为涉及一个既定的目标。如果从dfs开始解决这道题，应该是一个decision tree。这道题不一样的事情是一个element可以有multiple operations，这也是为什么我们需要一个while loop，以及为什么对于每个element，我们要整合全部operations的combination。knapsack一般用2d dp，i一般代表access to the ith element, j代表capacity。memoization可以跳过subproblem computation，但仍然是dfs。dp[i][j]就可以只看dp[i-1][j], dp[i][j-1], and dp[i-1][j-1].


### 代码 - optimal
```python
class Solution(object):
    def minOperations(self, nums, sum):
        """
        :type nums: List[int]
        :type sum: int
        :rtype: int
        """
        INF = float('inf')
        dp = [INF] * (sum + 1)
        dp[0] = 0

        for x in nums:
            cands = {}
            #value, exponent: multiply case
            v, e = x, 0
            while v <= sum:
                if e < cands.get(v, INF):
                    cands[v] = e
                v *= 2
                e += 1
            #divide case
            v, e = x, 0
            while v > 0:
                v //= 2
                e += 1
                if v <= sum and e < cands.get(v, INF):
                    cands[v] = e
            #0/1 knapsack, we make a copy to avoid reading and writing from the same array
            # dp[j]: how many steps can we make sum exactly j
            dp_next = dp[:]
            for val, cost in cands.items():
                if val == 0:
                    continue
                for j in range(sum, val - 1, -1):
                    if dp[j - val] + cost < dp_next[j]:
                        dp_next[j] = dp[j - val] + cost
            dp = dp_next
        return dp[sum] if dp[sum] < INF else -1

```
### 代码 - 2d dp
```python
class Solution(object):
    def minOperations(self, nums, sum):
        INF = float('inf')
        n = len(nums)

        # dp[i][j] = min ops using first i elements to reach sum j
        dp = [[INF] * (sum + 1) for _ in range(n + 1)]
        dp[0][0] = 0

        for i in range(1, n + 1):
            x = nums[i - 1]

            # build candidates for x
            cands = {}
            v, e = x, 0
            while v <= sum:
                if e < cands.get(v, INF):
                    cands[v] = e
                v *= 2
                e += 1
            v, e = x, 0
            while v > 0:
                v //= 2
                e += 1
                if v <= sum and e < cands.get(v, INF):
                    cands[v] = e

            for j in range(sum + 1):
                # option 1: skip x
                dp[i][j] = dp[i - 1][j]

                # option 2: use x as some val
                for val, cost in cands.items():
                    if val <= j and dp[i - 1][j - val] + cost < dp[i][j]:
                        dp[i][j] = dp[i - 1][j - val] + cost

        return dp[n][sum] if dp[n][sum] < INF else -1
```

### 复杂度
- 时间: O(n×sum×log(sum))
- 空间: O(n*sum)

## Q4. Minimum Operations to Form Subset Sum II

**链接**: https://leetcode.com/problems/minimum-operations-to-form-subset-sum-ii/

### 思路
条件变成multiply和divide随意order，而不是multiply一定在divide之前，所以cand有了更多combination：选择用bfs shortest path

### 代码
```python
from collections import deque

def get_cands(x, sum_, cap):
    dist = {x: 0}
    q = deque([x])
    while q:
        v = q.popleft()
        d = dist[v]
        # multiply
        nv = v * 2
        if nv <= cap and nv not in dist:
            dist[nv] = d + 1
            q.append(nv)
        # divide
        nv = v // 2
        if nv not in dist:
            dist[nv] = d + 1
            q.append(nv)
    # keep only values that could matter for the target sum
    return {v: c for v, c in dist.items() if v <= sum_}
```
